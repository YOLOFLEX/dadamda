# 다담다 (Dadamda) 📦

> 내가 나중에 보고 싶은 모든 것을 다 담아두는 스마트 보관함

## 소개
**다담다**는 유튜브, 인스타그램, 블로그 등 다양한 플랫폼의 링크, 사진, 메모, 파일을
한 곳에 보관하고 Android와 PC에서 실시간으로 동기화하는 스마트 보관함 앱입니다.

## 주요 기능
- 🔗 링크 저장 & OG 썸네일 자동 추출
- 📝 텍스트 메모 보관
- 🖼️ 사진 & 파일 저장
- 🔄 Android ↔ PC 실시간 동기화
- 🔒 PIN / 생체인증 잠금
- 🏷️ 태그 & 카테고리 자동 추천
- 🔍 강력한 검색 기능
- 🌙 라이트 / 다크 모드

## 플랫폼
- Android (Google Play)
- Web
- Windows PC
